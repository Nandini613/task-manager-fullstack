# Tasking Mission Control 🚀

A premium, data-driven "Mission Control" project management platform built with the MERN stack (MongoDB, Express, React, Node.js). Featuring a sleek Glassmorphism UI, advanced role-based access control, and real-time workload tracking.

## 🔗 Live Links
- **Frontend:** [https://courteous-tranquility-production-0e8c.up.railway.app](https://courteous-tranquility-production-0e8c.up.railway.app)
- **Backend API:** [https://task-manager-fullstack-production-fbb3.up.railway.app](https://task-manager-fullstack-production-fbb3.up.railway.app)

## ✨ Features

### 👑 Admin Mission Control
- **Interactive Team Management:** Real-time member workload indicators and active/suspended toggles.
- **Master Taskboard:** High-impact Kanban layout with drag-and-drop mechanics.
- **Global Categories:** Card-based workspace for standardizing tags and organization.
- **Advanced Settings:** Workspace branding and data export hub.

### 👤 Member Dashboard
- **My Inbox:** High-priority and actionable items feed.
- **My Today:** Focused view of tasks due today.
- **Upcoming:** Lookahead view for future tasks.
- **Assigned to Me:** Comprehensive directory of personal responsibilities.

### 🎨 Design System
- **Glassmorphism:** Premium translucent panels with heavy backdrop blurs.
- **Aesthetics:** Sleek dark mode, vibrant indigo accents, and smooth micro-animations.
- **Responsive:** Fully optimized for desktop and mobile experiences.

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Vanilla CSS (Glassmorphism), Axios.
- **Backend:** Node.js, Express, MongoDB (Mongoose).
- **Security:** JWT Authentication, Role-Based Access Control (RBAC).
- **Deployment:** Railway (Fullstack).

## 🚀 Deployment Config
The project is set up for automatic deployment on Railway.
- **Server Root:** `/server` (Variables: `MONGO_URI`, `JWT_SECRET`, `PORT`, `NODE_ENV`, `CLIENT_URL`)
- **Client Root:** `/client` (Variables: `VITE_API_URL`)
